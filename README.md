# Soc Ops — Python Agent Lab

[![Python](https://img.shields.io/badge/Python-Agent%20Lab-3776AB?logo=python)](https://www.python.org/) [![Source](https://img.shields.io/badge/Source-GitHub-181717?logo=github)](https://github.com/kandisaikishore/agent-lab-python)

Soc Ops is a social-bingo game for in-person mixers: participants find people who match prompt questions and aim to complete five in a row. The repository also contains a guided lab for learning agent-oriented development workflows.

## Project highlights

- Social-bingo activity designed for in-person networking
- Step-by-step workshop guide covering setup, context engineering, design, and agent workflows
- Workshop materials for learning by building
- A place to practise structured prompts and AI-assisted development

## Getting started

```bash
git clone https://github.com/kandisaikishore/agent-lab-python.git
cd agent-lab-python
```

Follow the setup steps in the lab guide and review the `workshop/` directory for supporting material. Refer to the repository's own configuration for runtime prerequisites and launch commands.
